== Scope

Wave 6 closes the remaining legacy `EventSubscriber` bucket after the subscriber/listener cleanup waves.

== Canonical change

* `src/EventSubscriber/DomainEventsToOutboxSubscriber.php` is moved to `src/Subscriber/Outbox/DomainEventsToOutboxSubscriber.php`.
* Namespace changes from `App\EventSubscriber` to `App\Subscriber\Outbox`.
* `config/services.yaml` keeps `App\Subscriber\` and `App\Listener\` resources and explicitly tags the Doctrine event subscriber.
* `config/services_audit.yaml` is repaired to reference `App\Subscriber\ApiAuditSubscriber` after Wave 4.

== Non-goals

* No entity-first migration changes are made in this wave.
* No broad Service-layer taxonomy move is made in this wave.
* No cumulative snapshot or destructive repository replacement is introduced.
