# Root cleanup map

This directory collects materials migrated out of the repository root to keep the RC surface clean.

- `guides/` — migrated operational and deploy guides kept for reference
- `history/` — historical release and readiness notes
- `archive/analysis/` — lint, collision, and analysis outputs
- `archive/feeds/` — archived NDJSON feed artifacts
- `archive/reports/` — old change and deletion reports
- `archive/manifests/` — historical root manifests and milestone files
- `archive/ci/` — archived root-era CI drafts
- `runbook/` — runbooks that no longer need their own root folder

Current authoritative operational entry points are the root docs (`README.md`, `README_EXTRAS.md`, `README_RELEASE.md`, `UPGRADE.md`) together with the active docs under `deploy/` and `docs/`.
