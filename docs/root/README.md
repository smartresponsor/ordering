# Root documentation index

This directory contains documentation and historical artifacts that previously lived in the repository root.

## Guides
- `guides/` — operational and topical guides relocated from root
- `runbook/docs/root/runbook/RUNBOOK.md` — operational runbook moved out of root
- `history/` — release fragments, alpha notes, and wave-era readmes

## Archive
- `archive/reports/` — generated lint, audit, collision, and wave support reports that were cluttering root
- `archive/feeds/` — ndjson feeds retained for traceability but removed from root

## Why this exists
The component is already in RC-range maturity, so root should privilege stable runtime/build/deploy surfaces over archival text clutter.
